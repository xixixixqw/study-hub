fix(deploy): 用 overrides 钉死 unrs-resolver，根治 Invalid Version

病根：eslint-import-resolver-typescript 的传递依赖 unrs-resolver
在非 macOS 平台下，npm 会为 @unrs/resolver-binding-darwin-arm64
生成 version 为 null 的残缺条目，Netlify 严格安装时读到空版本
即抛 npm error Invalid Version（且不指明是哪个包）。

之前删单条无效——npm 重新解析会再次生成。

根治：package.json 加 overrides 钉死 unrs-resolver@1.12.2，
重新生成 lock 后残缺条目彻底消失（0 异常）。
